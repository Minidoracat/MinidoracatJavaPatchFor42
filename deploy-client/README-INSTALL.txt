Minidoracat Client Patch — 實體隱形觀測＋修復（適用 Project Zomboid 42.20.0）
================================================================================

這個 patch 做什麼？
--------------------------------------------------------------------------------
針對「隊友/殭屍/車輛只剩影子和名牌、3D 模型看不到」的問題：
1.（修復）把遊戲貼圖載入管線的 50MB 記憶體門檻放寬到 1GB——原版超過 50MB 時
   載入執行緒會無限等待，導致新進視野的實體長時間載不出模型。
2.（觀測）在遊戲 log（console.txt）記錄水位數據，用來證明原因、驗證修復效果。

記憶體說明：放寬的是一般記憶體（RAM）的使用上限，不是顯示記憶體（VRAM）。
原本會「卡住等待」的時刻改為「多用一些 RAM 繼續載入」，最壞情況可能比原版
多用 1GB 或更多的 RAM。這是給受影響玩家的實驗版本，**建議 16GB 以上 RAM 的
電腦使用**；若你的電腦 RAM 較小（8GB 以下），請先不要安裝，回報給貓大即可。

重要：如果玩了幾小時後隱形又出現——這是遊戲本身的記憶體洩漏造成的
（我們正在做根治版），此時請「完全關閉遊戲再重開」（不是斷線重連，
重連沒有用），重開後又能正常玩幾小時。

安裝方式
--------------------------------------------------------------------------------
1. 完全關閉遊戲。
2. 把這個 zip 的「全部內容」解壓到任何資料夾（桌面、下載資料夾都可以）。
3. 雙擊「install.bat」。它會自動從 Steam 找到遊戲安裝位置並顯示出來，
   然後依序驗證：
   - 遊戲版本是否為 42.20.0（檔案指紋比對，版本不符會拒絕安裝）
   - 是否已有其他 patch 佔用同位置（有衝突會拒絕安裝）
   全部通過才會複製檔案，並在複製後再次驗證檔案指紋。看到 [OK] 才算安裝完成。
4. 正常啟動遊戲即可。不影響 Steam、工作坊與其他玩家。

（若自動偵測失敗：把 zip 內容改解壓到遊戲資料夾——Steam 遊戲庫 →
  Project Zomboid 右鍵 → 管理 → 瀏覽本機檔案——再執行 install.bat 即可。）

怎麼確認 patch 有生效？
--------------------------------------------------------------------------------
進入伺服器玩一下之後，開啟 %UserProfile%\Zomboid\console.txt，
搜尋「TexPipelineGuard」，看到這一行就代表生效：
  [MinidoracatJavaPatch][TexPipelineGuard] active vanillaLimitBytes=52428800 patchedLimitBytes=1073741824

log 裡「vanillaStallSamples=」的數字代表「原版遊戲在那個時刻會開始卡住等待」
的取樣次數；「aboveVanillaMs=」代表連續超標持續的毫秒數——這些就是問題
真的發生過、而 patch 已經放行的證據。回報時請把 console.txt 一起提供。

移除方式
--------------------------------------------------------------------------------
雙擊「uninstall.bat」（跟 install.bat 放在一起的那個，同樣會自動找到遊戲位置）。
它只會刪除本 patch 自己的兩個檔案（刪除前會先比對檔案指紋，
不是本 patch 的檔案一律不動）。

注意事項
--------------------------------------------------------------------------------
* 只適用遊戲版本 42.20.0（install.bat 會自動擋版本不符）。
  遊戲更新版本後請先執行 uninstall.bat 移除，等新版本重新製作。
* 這是給受影響玩家的個人測試版，請勿再散布或上傳到工作坊。
* 本 patch 不改遊戲玩法、不碰網路封包，對伺服器與其他玩家完全無影響。
* 有任何異常（進不了遊戲、當機、電腦變很卡），執行 uninstall.bat 即可恢復原狀。
