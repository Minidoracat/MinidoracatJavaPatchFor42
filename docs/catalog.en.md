# Patch catalog

**English** | [繁體中文](catalog.md) · [Back to README](../README.md)

Every patch in this repository, by area: what goes wrong in vanilla, what the patch does and whether we have reported it to TIS. The link in the first column opens the technical write-up of that patch in [patches.en.md](patches.en.md) (root cause with bytecode evidence, safety argument, checks, measured results). On 42.22.2 the server patches change 89 classes at 270 patch sites, with 113 helper classes.


Status is the default on 42.22.2. Every server patch has a `-Dmdc.*` kill switch (see its section) unless
noted. **TIS**: a topic number links to our forum report; "draft" means a report is written but not posted;
"not reported" means no report yet. Patches retired because 42.22.2 fixed the issue are listed under
[Fixed upstream](#fixed-upstream).

| W107 Trailer animals from background vehicle loading ([2do](patches.en.md#2do)) | Loading a vehicle on the `ServerPlayersVehicles` thread puts its saved animals into the trailer on that thread, which removes them from the world (engine, cell lists, hutches, zones) and writes the animal sync maps the main loop uses.
